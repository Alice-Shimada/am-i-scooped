目前安全

截止日以前 Batch Normalization 与 Layer Normalization 已分别公开，Layer Normalization 还明确比较了二者和 batch-size 差异；但检索未发现任何截止日前来源在同一层中端到端学习两套均值、方差统计的组合权重，因此完整混合机制仍属独特。

现在做什么

继续把可学习的统计混合层作为核心贡献，同时把 BN 和 LN 明确列为已知候选；不要把 mini-batch 统计、单样本 layer 统计或 batch-size 问题本身宣称为新。

Layer Normalization ↗

日期：2016-07-21 · 版本：arXiv:1607.06450v1

LN v1 在单个训练样本的一层全部隐藏单元上计算均值和方差，明确指出不限制 mini-batch 大小，并直接比较 BN 与 LN 在 batch size 128 和 4 下的表现。

核对证据与差异

证据位置

摘要；§3 式(3)；§5.1 式(5)与表1；§6.6 Figure 6 说明

与当前工作的差异

论文选择 LN 统计作为 BN 的替代方案；没有在同一归一化层同时使用两者，更没有学习均值和方差的组合权重。

原文摘录

different training cases have different normalization terms

关联主张：C1 · C3

下一步

  • 把均值权重和方差权重的参数化、约束与反向传播写成核心算法，突出它们不是 BN/LN 后处理的 scale 和 shift。
  • 用多个 batch size 展示所学权重随层和训练条件的变化，并与单独 BN、LN 做消融。
  • 在相关工作中将 BN 和 LN 作为已知非中心组件分别归因，主张限定为端到端统计混合机制。
