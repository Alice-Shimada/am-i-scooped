# 历史回放：截至 2016-08-01 的可学习归一化

这个公开示例说明：是否保留主张内部的关系，会直接影响研究重合判断。它回放一个已归档的校准案例，不是一次新的文献检索。

[`prompt.txt`](prompt.txt) 完整保留了原始中文输入。输入没有论文名、作者、URL、arXiv 编号或方法名，只描述了 mini-batch 统计、单样本 layer 统计，以及学习均值和方差组合权重。两个归档运行都由模型独立找到原始论文。

## 输入与运行条件

案例要求检索截至 2016-08-01 的公开文献，分别判断已知部分和仍然独特的部分。两个对照臂都在 2026-10-08 运行，模型均为 `gpt-5.6-sol`，reasoning 均为 `high`。

## 归档对照

| 对照臂 | 归档结论 | 归档输出摘要 |
|---|---|---|
| 未使用 skill（基线） | `risk` / 已有风险 | BN 与 LN 已分别给出两种候选统计；截止日前没有检索到学习二者均值和方差组合权重的方法，但基线仍把已知候选视为一项独立受威胁的主张。 |
| 使用修订后的 skill | `safe` / 目前安全 | BN 与 LN 被记录为已知的非中心组件；中心主张是同一层内同时计算两套统计并学习如何分别组合均值和方差，而两篇截止日前的论文都没有建立这一完整机制。 |

两个对照臂对研究事实的判断一致：

- [Batch Normalization v1](https://arxiv.org/html/1502.03167v1) 在截止日前使用 mini-batch 统计。
- [Layer Normalization v1](https://arxiv.org/html/1607.06450v1) 在截止日前使用单样本 layer 统计，并讨论 batch size 的影响。
- 已核对的截止日前来源都没有在同一归一化层中学习 BN/LN 联合权重。
- 基线还找到截止日之后公开的 [Switchable Normalization](https://arxiv.org/abs/1806.10779)，将其作为较晚出现的直接可学习混合方案。

结论变化来自主张拆分规则。修订后的工作流保留“同时计算两个候选并学习联合权重”这一整体关系，把 BN 和 LN 组件本身标记为已知但非中心；基线拆分得更激进，把已知组件提升为一项独立受威胁的贡献。
